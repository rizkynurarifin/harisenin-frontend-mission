# Harisenin Frontend Missions 🚀

This repository contains a collection of frontend development projects completed during the **Harisenin Bootcamp**. The projects progress from Intermediate to Advanced levels, focusing on building modern, responsive, and high-performance web applications.

## 🛠️ Tech Stack

* **Framework:** [React 19](https://react.dev/)
* **Language:** [TypeScript](https://www.typescriptlang.org/)
* **Styling:** [Tailwind CSS v4](https://tailwindcss.com/)
* **Build Tool:** [Vite](https://vitejs.dev/)
* **Routing:** [React Router v7](https://reactrouter.com/)
* **Icons:** [Lucide React](https://lucide.dev/)

## 🚀 Getting Started

To run the project locally, follow these steps:

1.  **Clone the repository:**
    ```bash
    git clone [https://github.com/rizkynurarifin/harisenin-frontend-mission.git](https://github.com/rizkynurarifin/harisenin-frontend-mission.git)
    ```
2.  **Navigate to the folder:**
    ```bash
    cd harisenin-frontend-mission
    ```
3.  **Install dependencies:**
    ```bash
    npm install
    ```
4.  **Run the development server:**
    ```bash
    npm run dev
    ```
